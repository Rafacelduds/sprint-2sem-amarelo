# Constituição do projeto

## Princípios

1. Toda funcionalidade começa com uma especificação curta em `specs/`.
2. O contrato OpenAPI é a fonte do cliente TypeScript.
3. API e coletor permanecem processos separados.
4. Dados brutos são imutáveis no S3; derivados são gravados em Parquet.
5. Alterações entram por PR com evidências de testes e revisão de outro integrante.
